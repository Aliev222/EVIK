# Мок-режим для тестирования

Этот файл описывает как включать и выключать мок-режим для тестирования приложения без подключения к реальному бэкенду.

## 🚀 Быстрый старт

### Включить мок-режим (заглушки) - По умолчанию
```bash
# Простые команды запуска:
start_mock.bat     # Выбор платформы через меню
start_real.bat     # Запуск с реальным API

# Или вручную:
cd frontend
flutter run --dart-define=USE_MOCK_DATA=true

# Веб версия
flutter run -d chrome --web-port 3000 --dart-define=USE_MOCK_DATA=true

# Windows
flutter run -d windows --dart-define=USE_MOCK_DATA=true
```

### Выключить мок-режим (реальный API)
```bash
# Flutter run с реальным API
flutter run --dart-define=USE_MOCK_DATA=false

# Веб версия с реальным API
flutter run -d chrome --web-port 3000 --dart-define=USE_MOCK_DATA=false
```

## 📱 Что включает мок-режим

### 1. API Заглушки (api_client_stub.dart)
- **Аутентификация**: Автоматическое "успешное" подключение
- **Пользователи**: Генерация тестовых профилей
- **Водители**: Случайные данные водителей с документами
- **Заказы**: Создание, история, доступные заказы
- **Геолокация**: Тестовые координаты вокруг Москвы

### 2. WebSocket Заглушки
- **Автоподключение**: Имитация успешного WS соединения
- **Обновления заказов**: Автоматическая смена статусов каждые 5 секунд
- **Последовательность**: searching → assigned → onWay → arrived → evacuating → completed

### 3. Тестовые данные

#### Клиент:
- Имя: "Тестовый Пользователь"
- Телефон: +7999123456X
- Рейтинг: 4.5-5.0
- Заказы: 1-50

#### Водитель:
- Имя: "Тестовый Водитель" 
- Телефон: +7999654321X
- Рейтинг: 4.0-5.0
- Машина: Toyota Hiace А123АА 77
- Статус: случайный (approved/pending/rejected)
- Заработок: 500-2000₽/день

#### Заказы:
- Адреса: Тестовые улицы вокруг Москвы
- Цена: 800-2800₽
- Расстояние: 5-50 км
- Время: 15-75 минут

## 🔧 Технические детали

### Файлы с мок-логикой:
- `frontend/lib/core/network/api_client_stub.dart` - HTTP заглушки
- `frontend/lib/core/realtime/websocket_client_io.dart` - WebSocket заглушки
- `frontend/lib/core/constants/app_constants.dart` - Флаг `useMockData`

### Логика переключения:
```dart
// В app_constants.dart
static const bool useMockData =
    bool.fromEnvironment('USE_MOCK_DATA', defaultValue: true);

// В api_client_stub.dart
ApiClient createPlatformApiClient({String baseUrl = defaultApiBaseUrl}) {
  if (AppConstants.useMockData) {
    return MockApiClient(); // Мок
  }
  return HttpApiClient(baseUrl: baseUrl); // Реальный API
}
```

## 🎯 Сценарии тестирования

### Для клиента:
1. **Регистрация/вход**: Введите любой номер телефона → Введите ЛЮБОЙ 6-значный код (например: 123456)
2. Создание заказа (автоматическое принятие)
3. Отслеживание заказа (автоматическая смена статусов)
4. Просмотр истории (сгенерированная история)

### Для водителя:
1. **Регистрация/вход**: Введите любой номер телефона → Введите ЛЮБОЙ 6-значный код (например: 654321)
2. Загрузка документов (автоматическое принятие)
3. Переключение онлайн/офлайн статуса
4. Просмотр доступных заказов (автогенерация)
5. Принятие и выполнение заказов
6. Просмотр заработка (тестовые данные)

## 🚨 Важные особенности

1. **Задержки**: Мок API имитирует сетевые задержки (200-1000мс)
2. **Случайность**: Некоторые ответы генерируются случайно
3. **Логи**: Все мок-запросы выводятся в консоль с префиксом `[MOCK API]`
4. **WebSocket**: Автообновления заказов каждые 5 секунд
5. **Геолокация**: Все координаты вокруг Москвы (±0.1 градуса)

## 🔄 Переключение во время разработки

Для быстрого переключения без перезапуска можно добавить кнопку в UI:

```dart
// Временная кнопка для переключения режимов
if (kDebugMode) {
  IconButton(
    icon: Icon(AppConstants.useMockData ? Icons.cloud_off : Icons.cloud),
    onPressed: () {
      // Логика переключения
    },
  ),
}
```

## ⚠️ Ограничения мок-режима

1. Файлы и изображения не загружаются реально
2. Геолокация не отслеживается реально
3. Push-уведомления не отправляются
4. Платежи не обрабатываются
5. База данных не используется

## 🏗️ Для разработчиков

### Добавление новых мок-данных:

1. Откройте `api_client_stub.dart`
2. Найдите соответствующий метод `_handleXxxEndpoints`
3. Добавьте новый путь и ответ
4. При необходимости создайте новый генератор данных `_generateMockXxx`

### Отладка мок-режима:

Все мок-запросы логируются:
```
[MOCK API] POST /auth/send-sms
[MOCK WS] Connected to ws://localhost:8080/ws/orders
[MOCK WS] Sending order update: assigned
```
