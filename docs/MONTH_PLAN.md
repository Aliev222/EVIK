# Авро — План на месяц до ИП

> Цель: к концу месяца — готовое приложение (клиент+водитель), клиентский сайт,
> пересобранная админка («пульт управления»), маркетинговая воронка, и всё
> подготовлено к запуску платежей, чтобы после регистрации ИП go-live был
> вопросом конфигурации, а не переписывания.
> Метод: техлид даёт точный промпт → агент реализует → техлид проверяет по коду.
> Это структура с ежедневными целями, а не жёсткий контракт — двигаем по факту.
> Дата старта плана: август 2026.

- **Неделя 1:** 14–20 августа — frontend + задел на VPS
- **Неделя 2:** 21–27 августа — пересборка админки
- **Неделя 3:** 28 августа – 3 сентября — сайт + воронка + нагрузка

- **~11–13 сентября:** готов идти открывать ИП

Опережение по backend: денежные фиксы, тесты, security, Redis-лимитер (День 3) —

## Что после ИП (Фаза go-live, вне этого месяца)
1. Активировать боевой эквайринг (live-ключи ЮKassa/Точка).
2. Точка Банк/Cyclops: регистрация площадки, доступ, боевые ключи.
3. Sandbox → одна маленькая реальная транзакция (10₽) → проверка live.
4. Выключить stub-режимы, открыть для пользователей.

## Что вне кода (на тебе)
- Регистрация ИП, договор с банком/эквайрингом, доступ Cyclops.
- Рекламные кабинеты, бюджеты, креативы (я помогаю с лендингами/воронкой/контентом, но закупку рекламы ведёшь ты).
- Выбор SMS-провайдера, аккаунт.

## Принцип приёмки (каждый день)
Задача принята только после проверки техлидом по коду (не по отчёту агента):
функциональность, архитектура Авро, деньги/бизнес-логика, регрессии, тесты,
документация. «Готово» ≠ сделано.
